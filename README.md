# Rayyan & Mariam — Premium Digital Nikah Invitation

Vercel-ready Next.js website. No API key required.

## Run
npm install
npm run dev

## Deploy
Push this folder to GitHub, import it at Vercel, then Deploy.

The Google Maps button uses a search link for The Coconut Garden, Gulistan e Johar, Karachi. Replace it with the exact venue pin if desired.

Note: the music button is a UI placeholder; to add actual Qawali audio, place an MP3 in `public/` and wire it to an HTML Audio element.
